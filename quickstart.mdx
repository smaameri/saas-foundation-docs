Follow these steps to configure and launch the SaaS Foundation starter template s on your
local machine.

## Prerequisites

Install the following tools before you begin:

<CardGroup cols={3}>
  <Card title="Node.js" icon="node-js" iconType="brands" href="https://nodejs.org/">
    Run the application and its development tooling.
  </Card>
  <Card title="pnpm" icon="box" href="https://pnpm.io/installation">
    Install dependencies and run project scripts.
  </Card>
  <Card title="Docker" icon="docker" iconType="brands" href="https://docs.docker.com/get-docker/">
    Run the local PostgreSQL database.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Clone the repository">
    Clone SaaS Foundation and enter the project directory.

    ```bash
    git clone git@github.com:smaameri/saas-foundation.git
    cd saas-foundation
    ```
  </Step>

  <Step title="Install dependencies">
    Install the project packages with pnpm.

    ```bash
    pnpm install
    ```
  </Step>

  <Step title="Set up the application">
    Run the interactive setup command to
    - launch the docker container with the postgres database inside it
    - create the admin user you will use to login to the application
    - create an initial organization you are a member of
    - seed the database with some initial data

    ```bash
    pnpm app:setup
    ```
  </Step>

  <Step title="Start the development server">
    Launch SaaS Foundation platform development server.

    ```bash
    pnpm dev
    ```
  </Step>
</Steps>

## Configure email

To send invitations and account emails, create an account with
[Resend](https://resend.com), generate an API key, and add it to `.env`.

```dotenv
RESEND_API_KEY=re_...
```

Verify your sending domain in Resend, then configure the sender address.

```dotenv
EMAIL_FROM="notifications@your-domain.com"
```

<CustomTip>
  You can skip the email configuration while evaluating the application
  locally. Add it before testing invitation and account email flows.
</CustomTip>
