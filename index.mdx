Starting a new B2B SaaS project? Want to hit the ground running and get straight to work on app features?

SaaS foundation takes care of the repetitive, boilerplate code you need to kick off a multi-tenant B2B SaaS app.

# Features

An intentionally minimalist and carefully designed starter template that gives you
- an Admin and Customer Portal
- Flows for adding Users, Organizations, Members, and inviting people.
- Login and Password Reset flows.
- Well thought-out API formats.
- Error handling.
- Data Tables for rendering lists on the frontend, including with filter and search features.

Start up the entire portal in a few commands and get straight to work on the features that are actually custom to your
app.

# Stack

The template is built on a modern TypeScript stack that gives a powerset of features and packages to build on as you
grow your app.
