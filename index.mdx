Starting a new B2B SaaS project? Want to hit the ground running and get straight to work on app features?

SaaS Foundation gives you a solid base to kick off a multi-tenant B2B SaaS app, providing a cleanly designed and powerful
set of flows for managing users, organizations, members, invitations and auth flows. All built on top of a modern and powerful
TypeScript stack, that serve as a great foundation for your next project.

Start up the entire portal in a just few commands and get straight to work on the features that are actually unique to your
app.

# Features

An intentionally minimalist and carefully designed starter template that gives you
- an Admin and Customer Portal
- Flows for adding Users, Organizations, Members, and inviting people.
- Login and Password Reset flows.
- Structured API formats for lists, pagination, success and error responses.
- Error handling middleware.
- Data Tables for rendering lists on the frontend, including with filter and search features.

These are a set of core and well-designed features that are generic to most B2B SaaS apps, so you don't need to
reinvent the wheel, again! And you can get straight to work on your actual product.

Agent.MD files are included, allowing you to prototype at crazy fast speeds, within the light, well-designed, and loosely coupled
architecture that the template provides.

# Stack

The template is built on a modern TypeScript stack that gives a powerfull of features and packages to build on as you
grow your app.
